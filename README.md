## 🚀 Key Features

- **Dynamic Hero Section:** Rotating typing role animation, 3D interactive tilt profile card, status indicator, and quick CTA buttons.
- **Interactive Developer Console / Terminal:** Simulated CLI environment where recruiters can type commands (`help`, `about`, `skills`, `education`, `projects`, `contact`, `resume`) or click command chips.
- **Glassmorphism & High-Tech Design System:** Modern dark mode aesthetic by default with instant toggle to light mode (stored in `localStorage`).
- **Constellation Particle Canvas:** Physics-based interactive particle network responding smoothly to screen interactions.
- **Categorized Skills Matrix:** Interactive filtering (Languages, Web, Backend, UI/UX) with animated skill progress bars.
- **Project Case Studies & Modals:** Rich modals showing architecture details, code snippets, problem overviews, and repository links.
- **Integrated CV Viewer & PDF Print:** Printable, clean executive resume layout ready for PDF export or immediate printing.
- **Interactive Contact Form:** Instant validation, character counter, toast feedback, and email fallback.
- **100% Responsive & Zero Build Overhead:** Fast, lightweight, pure modern HTML5, CSS3, and JavaScript without external build steps.

## 🌐 How to Deploy to GitHub Pages

1. Push all code to your `main` branch:
   ```bash
   git add .
   git commit -m "feat: complete modern personal portfolio with interactive terminal"
   git push -u origin main
   ```
2. In your GitHub repository, navigate to **Settings** > **Pages** (under Code and automation).
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Within 1-2 minutes, your website will be live at:
   `https://irushitheshala322.github.io/Portfolio/`
